I've updated `features.md` so ESCO and O\*NET are the chosen data sources for skills and occupations.

**How the two fit together**
- **ESCO is the main skill list.** It's more detailed (about 14,000 skills) and available in 28 languages.
- **O\*NET adds detail on top.** It rates how important each skill is for an occupation and at what level, and flags "hot technologies" and in-demand occupations.
- **Each skill gets one ID in our database,** with links to both its ESCO and O\*NET entries, so the two lists line up.

**How we'll use them**
- **Load the full download files first, use the live APIs second.** Both offer free downloads of the complete data, so we load those into Postgres at setup. The APIs are only for small lookups, which avoids rate limits and keeps things fast.
- **Pin the ESCO version.** The ESCO API defaults to an old version (v1.0.9), which returns noticeably different results. We'll always ask for a specific newer version and record it on each skill.
- **Credit both sources on screen.** O\*NET's license requires attribution, so there's a "data from ESCO and O\*NET" footer in the dashboard and briefs.
