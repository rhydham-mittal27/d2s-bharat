\section{Approach}\label{sec:approach}

The analysis moves from \emph{descriptive} (what the market and employees look like) to
\emph{diagnostic} (which skills and traits are associated with pay and success) to
\emph{prescriptive} (what to teach first). Figure~\ref{fig:flow} shows the overall flow.

\textbf{Why these methods.}
\begin{itemize}
  \item \textbf{Rank-based tests and effect sizes} (Mann--Whitney U \citep{mannwhitney1947},
        rank-biserial correlation \citep{kerby2014}) because the JDS 1--5 scores are bounded and
        heavily skewed towards the ceiling; Holm correction \citep{holm1979} controls the five
        tests per dataset. Bootstrap CIs \citep{efron1993} quantify uncertainty.
  \item \textbf{L2-regularised logistic regression and depth-limited trees} \citep{breiman1984}
        for the small JDS/SDS samples. With five predictors the smaller class gives 13.2 (JDS) and
        15.2 (SDS) events per predictor, a favourable ratio \citep{peduzzi1996,vittinghoff2007};
        complexity is still kept deliberately low and every model is scored by repeated stratified
        5-fold cross-validation (20 repeats) against a majority-class baseline, with a label-permutation
        test of the AUC.
  \item \textbf{Ordinal logistic regression} \citep{mccullagh1980} for pay, because salary is
        given in six ordered bands, not exact amounts; it lets us control for experience and role
        family. Benjamini--Hochberg FDR \citep{benjamini1995} controls the 30--40 skills tested.
  \item \textbf{Association rules} \citep{agrawal1994} reveal skill bundles that should be taught
        together.
  \item \textbf{Integer optimisation} (CP-SAT \citep{cpsat}) because courses are all-or-nothing,
        have batch sizes and prerequisites; a linear relaxation would propose fractional courses.
\end{itemize}
