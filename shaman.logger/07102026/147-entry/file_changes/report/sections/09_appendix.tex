\section{Reproducibility}\label{app:repro}

All analysis is scripted, seeded (seed 42) and re-runnable from the project repository
(\texttt{backend/}). Run in this order (Python 3.13, \texttt{uv}):

\begin{table}[H]\centering\small
\begin{tabularx}{\linewidth}{@{}L{5.6cm}Y@{}}
\toprule
Script & Produces\\
\midrule
\texttt{scripts/run\_sas\_ingestion.py} & cleaned postings, tag mapping, text-calibration test\\
\texttt{scripts/run\_rq2\_rq3.py} & RQ2/RQ3 tests, models, odds ratios, trees\\
\texttt{scripts/run\_rq1.py} & role families, canonical skills, demand, pay models, rules, triangulation\\
\texttt{scripts/run\_rq4.py} & optimal plan, sensitivity, Pareto, robustness\\
\texttt{scripts/make\_report\_assets.py} & cleaned CSVs, LaTeX tables, figures for this report\\
\bottomrule
\end{tabularx}
\end{table}

Core modules: \texttt{d2s/ingest/} (parsing, skill mapping), \texttt{d2s/analysis/} (traits, jobs,
plan), \texttt{d2s/engine/} (CP-SAT model, sensitivity, Pareto, why-not). 49 automated tests check
data handling, statistics and the optimiser (e.g.\ that every plan respects budget, prerequisites
and either/or groups, and that the optimiser matches brute force on a small instance). Cleaned data:
\texttt{dataset/processed/clean/}.

\section{Role-family rules}\label{app:families}
Titles are lower-cased and matched against ordered keyword rules; the first match wins.
\begin{enumerate}
  \item \textbf{Data Science / ML:} data scien, machine learning, ML, deep learning, AI, NLP,
        computer vision, statistician, quant, predictive, modeller/modelling.
  \item \textbf{Data Engineering:} data engineer, big data, hadoop, spark, ETL, data architect,
        data warehouse, databricks, kafka, informatica, data platform, DBA, database, data model.
  \item \textbf{Analytics / BI:} data analy, analytics, BI, business intelligence, Power BI, Tableau,
        MIS, reporting, insight, SAS, statistic, research analyst.
  \item \textbf{Business Analysis / Product:} business analy, BA, product manager/owner/analyst,
        functional or business consultant.
  \item \textbf{Marketing / SEO / Content}, \textbf{Finance / Risk}, \textbf{Software / IT},
        \textbf{Sales / Ops / HR / Support}, \textbf{Management / Consulting} (keyword lists in
        \texttt{d2s/analysis/jobs.py}); generic ``Analyst'' $\rightarrow$ Analytics / BI; else Other.
\end{enumerate}
