The failing test was a real bug in the skill matcher, and it's fixed. All 39 tests now pass with no warnings.

**The bug:** a skill name at the end of a sentence was never matched by exact text. `"…Python."` was read as the word `python.`, so it didn't match the skill `python`. That would have silently missed skills in real job posts. The fix in `d2s/ml/skills.py` strips trailing full stops from words, but keeps dots inside names like `Node.js` and `ASP.NET`. I added a test covering both cases.

**Cleaner test output:** I silenced the 4 warnings in `pyproject.toml`. Two come from OR-Tools on Python 3.13; the other is a forecasting model hitting divide-by-zero on the tiny test series. That model just scores badly there and isn't picked. None of them affect results.
